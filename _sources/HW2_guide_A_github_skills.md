# HW 2 Guide A: GitHub Skills

HW 1 covered the basics of Git and GitHub. These three tutorials cover what
comes next: publishing a website from a repository, and working on code with
other people. As before, each one runs inside a repository that you create
from a template, and a bot checks each step and replies with the next one as
you go.

## The three tutorials

1. [GitHub Pages](https://github.com/skills/github-pages): turn a repository
   into a live website. Part D of this assignment asks you to do the same with
   the site your pipeline builds, so do this one first.
2. [Review pull requests](https://github.com/skills/review-pull-requests):
   comment on a proposed change, suggest edits, and approve it. This is the
   peer code review that the job postings ask for, and it is how the class
   report and your final project are built.
3. [Resolve merge conflicts](https://github.com/skills/resolve-merge-conflicts):
   what to do when two people change the same lines. It will happen in your
   final project group.

Create each tutorial repository as **public** and in your own GitHub account,
not in the course organization, so that your completed work can be checked.

## Recording your work

Open `src/github_skills.py` in your HW 2 repository. For each tutorial, set
its `I_HAVE_COMPLETED_...` flag to `True` and paste the URL of the repository
you completed it in. Each tutorial is one test in `src/test_github_skills.py`
and worth one point.
