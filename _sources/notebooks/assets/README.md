# Notebook Assets

Drop screenshots for the notebooks in this folder (e.g. from the CME FedWatch
tool at https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html).

Notebooks reference these files with relative paths like `assets/<name>.png`
(notebooks execute with `src/` as the working directory). The course textbook
build copies this entire folder alongside the published notebooks, so the same
relative paths work there too.

Current files:

- `cme_zq_product_page.png` — CME's 30-Day Fed Funds futures (ZQ) product page
- `fedwatch_target_probabilities.png` — FedWatch's probability bars for the
  next FOMC meeting, captured the same day the data was pulled
